# Keyboop + OmniVoice — клавиатура и голос агента

**Два независимых инструмента для macOS:** [Keyboop](https://keyboop.com) автоматически исправляет неправильную раскладку, а [OmniVoice](https://github.com/k2-fsa/OmniVoice) озвучивает ответы ИИ-агента локально. Этот репозиторий содержит наши инструкции и **отдельный локальный голосовой сервер**. Он не включает чужой исходный код, веса модели или частные голоса.

## Установка

Требуются Mac с Apple Silicon (M1 или новее), Python 3.11, свободное место под модель (не менее 3 ГБ, дополнительно к зависимостям) и интернет для первоначальной установки.

1. Установи [Keyboop с официального сайта](https://keyboop.com), предоставь запрошенные разрешения macOS («Универсальный доступ» и, если понадобится, мониторинг ввода), затем выбери раскладки и горячие клавиши. Keyboop можно использовать совершенно отдельно.
2. Установи голосовую часть:
   ```sh
   git clone https://github.com/NickPicnick13/keyboop-omnivoice.git
   cd keyboop-omnivoice
   bash scripts/install.sh
   ```
3. По [официальной инструкции OmniVoice](https://github.com/k2-fsa/OmniVoice) загрузи веса модели, ознакомившись с лицензией. Экспортируй путь к каталогу с `model.safetensors`:
   ```sh
   export KOV_MODEL_DIR="/путь/к/модели"
   source .venv/bin/activate
   ```
4. Добавь свой голос или голос человека, который **дал согласие**. Нужен WAV-файл и точная расшифровка именно этой записи:
   ```sh
   keyboop-omnivoice add-voice narrator --file "/путь/к/образцу.wav" --text "Точный текст аудио"
   ```
   Или создай голос по описанию: `keyboop-omnivoice add-design narrator --instruction "Natural warm female Russian narrator"`.
5. Запусти `keyboop-omnivoice serve` (локальный порт **3912**). Проверка:
   ```sh
   curl -sS http://127.0.0.1:3912/health
   curl -sS http://127.0.0.1:3912/v1/audio/speech -H 'Content-Type: application/json' -d '{"voice":"narrator","input":"Привет, я твой агент."}' --output speech.wav
   ```
   Файл `speech.wav` содержит озвученный текст. Подключи к агенту OpenAI-совместимый TTS endpoint `http://127.0.0.1:3912/v1/audio/speech` (формат WAV).

## Управление

`keyboop-omnivoice doctor` — проверка окружения; `list-voices` — профили; `add-voice` / `add-design` — регистрация; `remove-voice` — удаление; `serve` — сервер. Все приватные образцы находятся за пределами Git. Сервер слушает **только локальный адрес**, аутентификации нет.

**Важно:** это альфа-версия интеграции. На новом Mac полностью автоматическая установка и голосовая генерация пока не сертифицированы. Официальный Keyboop — самостоятельное приложение. Исходники OmniVoice лицензированы отдельно от **некоммерческих** весов модели. Для коммерческого использования требуется изучить условия/получить права.
