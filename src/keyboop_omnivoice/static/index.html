3. Проверить озвучку

Первый запуск загружает модель в память; это может занять время.

4. Подключить к агенту

В настройках голосового клиента укажи локальный TTS endpoint: http://127.0.0.1:3912/v1/audio/speech.

Метод POST, JSON: {"input":"Привет!","voice":"narrator","response_format":"wav"}. Ответ — WAV. Некоторые агенты требуют небольшой адаптер для этого API.
