# Changelog

## 0.2.0-beta.1 — 2026-10-27

- Downloadable macOS installation bundle with double-click Install.command / Open Dashboard.command / Remove.command.
- Secure automatic official Keyboop download and Apple code-signature verification.
- Automatic Python environment and noncommercial OmniVoice model download with explicit acceptance.
- Localhost-only browser control panel: design a voice, clone with explicit consent, test speech and delete profiles.
- Per-user LaunchAgent, structured health status, bounded in-memory TTS cache, chunked replies.
- Real OmniVoice MPS synthesis and verified official Keyboop DMG; expanded unit/API/security tests and bilingual onboarding.
- No bundled weights, voice recordings or private machine configuration.

## 0.1.0 — 2026-10-27

- Initial developer-only integration proof of concept.
